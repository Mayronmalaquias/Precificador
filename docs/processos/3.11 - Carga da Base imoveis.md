# 3.11 — Carga da Base `imoveis` (CSV → Postgres)

> 🆕 Etapa que faltava entre [[3.10 - Scraper DFImóveis (execução)]] e
> [[3.12 - Geração de estudo_metricas]]. Código: repo **`Estudos`**, `BD/enviar_BD.py`.

## 1. Objetivo
Carregar os CSVs de coleta na tabela **`imoveis`** do banco `coleta_imobiliaria` (RDS), que é a
**base bruta acumulada** de mercado usada pela precificação ([[3.1 - Precificação por Mercado]]).

## 2. Regras de Negócio
- **Sempre append.** Não há `UPDATE`, `UPSERT` nem `DELETE` — a base **acumula** (coerente com a
  filosofia descrita em [[3.2 - Coleta de Mercado (Scraping)]]: guardar bruto, filtrar na análise).
- **Sem deduplicação na carga.** Rodar o mesmo arquivo duas vezes **duplica as linhas**.
- **Lista de cargas hardcoded** na constante `CARGAS` (arquivo + `data_coleta` de fallback) — editar
  o script a cada lote.
- **`portal` fixo = `"df"`.**
- **`data_coleta`:** extraída da coluna `horario` do CSV (só a parte da data);
  linha sem `horario` válido cai no `data_coleta` informado manualmente em `CARGAS`.
- **Normalização de colunas:** `strip` → `lower` → espaço vira `_`. Colunas esperadas ausentes são
  criadas como `NULL`.
- **Tipagem:** `area_util, preco, valor_m2, quartos, vagas, latitude, longitude` → numérico
  (`errors="coerce"`); textos → string com `strip`; `NaN/NaT/<NA>` e string vazia → `None` (NULL).
- **Colunas gravadas (18):** `area_util, preco, valor_m2, quartos, vagas, latitude, longitude,
  data_coleta, cidade, codigo, link, creci, anunciante, oferta, tipo, quadra, bairro, portal`.
- **Inserção em lote** com `execute_values`, `page_size=1000`; **commit por arquivo**.
- **Erro em qualquer arquivo → `rollback` + `raise`** (interrompe o lote inteiro).

> ⚠️ **Descasamento de nomes a validar:** o scraper ([[3.10 - Scraper DFImóveis (execução)]])
> emite `tipo` = operação, `tipo_imovel` = categoria e `data`; este script espera `oferta`,
> `tipo` e `horario`. Ou existe um passo de renomeação intermediário, ou o CSV usado na carga
> vem de outra origem/versão. **Confirmar antes de rodar uma carga nova.**

## 3. Fluxo
1. Editar `CARGAS` com os arquivos e as datas do lote.
2. `python BD/enviar_BD.py`.
3. Para cada arquivo: lê (`utf-8-sig`, `low_memory=False`) → `tratar_valores()` → `INSERT` em lote.
4. Log no console: colunas encontradas, total de linhas do CSV, total inserido.

## 4. Troubleshooting
| Sintoma | Causa provável (código) | Ação |
|---|---|---|
| Linhas duplicadas na `imoveis` | Carga repetida (sem dedup/idempotência) | Conferir por `data_coleta` antes de rodar; limpar manualmente |
| `Arquivo não encontrado: X` | Caminho relativo em `CARGAS` | Rodar a partir de `BD/` ou usar caminho absoluto |
| Todas as colunas viraram NULL | Separador/encoding do CSV diferente | O script lê só `sep=","`; converter o CSV antes |
| `data_coleta` errada | CSV sem coluna `horario` | Cai no fallback de `CARGAS` — conferir a data digitada |
| Erro no meio do lote | `rollback` + `raise` | Arquivos já commitados **permanecem**; retomar do arquivo que falhou |
| `preco`/`area_util` zerados | `to_numeric(errors="coerce")` engoliu formato BR | Verificar se o CSV veio com vírgula decimal |

**Riscos/lacunas:**
- 🔴 **Credencial do RDS hardcoded** como fallback de `os.getenv` (host, user e senha no arquivo,
  versionado). Liga direto a [[2.9 - Gestão de Segredos]].
- ⚠️ **Sem idempotência** — nenhuma chave natural (`codigo` + `data_coleta` + `portal`) impede recarga.
- ⚠️ **Sem log persistido** — só `print` no console.
