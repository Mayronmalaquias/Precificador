# 1.1 — Coleta de Leads / Captura no Site

## 1. Objetivo
Centralizar os leads do dia num só lugar e avisar a recepção.
- Trigger no Apps Script puxa leads do **C2S (Contact2Sale)**.
- Grava na planilha **Base Inteligência 61** (aba `Fato_Lead`).
- Dispara e-mail com os leads do dia para a recepção.
> **Evolução (to-be):** migrar da planilha para o **banco + sistema da Inteligência**.
> Ponto de partida: `POST /api/v1/admin/bases/importar/leads-contact2sale`.

## 2. Regras de Negócio
- **Frequência:** 1x/dia, 06:00, automático.
- **Escopo:** todos os leads do dia. Sem filtro (equipe/origem/status).
- **Deduplicação:** não existe. Reentrada em dias diferentes duplica.
- **Campos:** Data · Fonte · Contato · Relatório · Cliente · Telefone · Código · Atendimento · Equipe.
- **Destinatário:** 61@61imoveis.com.

## 3. Fluxo
Host: Apps Script vinculado à planilha Base Inteligência 61
(ID 1HQDdcbUMj276hnIbPs-WwdWHiUPzMhPRWt4HHRyYGnw · aba `Fato_Lead`). Gatilho diário 06:00.
1. 06:00 — trigger dispara.
2. Puxa do C2S via endpoint + token de validação (UrlFetchApp).
3. Envia e-mail p/ 61@61imoveis.com com os leads do dia.
4. Grava as linhas na aba `Fato_Lead`.
Helper: `legado/Bases/Base Inteligente/Filtrar_Leads.gs` (filtra por Código; fora do fluxo diário).

## 4. Troubleshooting
| Sintoma | Causa | Situação |
|---|---|---|
| Sem leads no dia | C2S fora do ar às 6h | Não envia; sem retry/alerta |
| Token | Expiração | Nunca expirou; sem renovação |
| E-mail não chega | Falha/quota | Sempre chegou |
| Duplicados | Sem dedup | Tratado manual pela recepção |

Lacunas: sem logs, sem monitoramento, falha silenciosa, sem dedup.

## Atualização — Importação Contact2Sale reativada (2026-08-07)

### O problema

O KPI "Leads" da Visão do Diretor dava **0** para qualquer período depois de 21/06/2026:

```text
leads_legado: 63.430 linhas · data de 2022-01-03 até 2026-06-21
created_at  : TODAS as 63.430 em 2026-06-24 21:21  (uma carga só)
```

Ou seja: `leads_legado` era a carga única da planilha legado feita em 24/06 e o importador do
Contact2Sale **nunca havia rodado**. Não existia `CONTACT2SALE_TOKEN` no `.env`.

### Correções

1. **Bug de limite:** `importar_contact2sale` aceitava `per_page` até 100, mas a API corta em 50
   — acima disso responde `403 "'perpage' must be less than or equal to 50"`. Capado em 50.
2. **Token** configurado no `.env` do backend (`CONTACT2SALE_TOKEN`).
3. **Backfill** de 22/06 a 07/08: `total_api=3730 · inseridos=3012 · duplicados=347 ·
   ignorados=371` (sem cliente). `leads_legado` foi para 66.530 linhas, até 07/08.
4. **Script de cron** `backend/importar_leads_c2s.py` — importa o dia anterior por padrão e
   aceita intervalo para backfill manual:

```bash
venv/bin/python importar_leads_c2s.py                     # ontem
venv/bin/python importar_leads_c2s.py 2026-06-22 2026-08-07  # intervalo
```

```cron
10 3 * * * cd /home/ubuntu/Precificador/backend && venv/bin/python importar_leads_c2s.py >> /home/ubuntu/leads_c2s.log 2>&1
```

O import é **idempotente** (dedup por `_dedupe_key` + `_existe_lead`).

### Notas da API

- Base: `https://api.contact2sale.com/integration`; token no header `Authorization`.
- Datas exigem o formato **`%FT%TZ`** (`2026-08-01T00:00:00Z`). Sem o `Z` a API responde
  `403 {"success":false,"message":"invalid date or strptime format"}` — o código já usava o
  formato certo.
- `GET /me` confirma a empresa e lista as filiais (61 Imóveis + AGUIA + …).

### Como o lead chega

`FONTE_MAP` traduz a origem do C2S para o código interno (`ImovelWeb→WI`, `DF imoveis→DF`,
`C2Sbot→DF`, `Facebook/Instagram Leads→99Web`…). O campo `equipe` recebe o id (`G610xx`) e
`atendimento` o id do corretor (`C610xx`).

> ⚠️ **Dois desvios que afetam relatórios:**
> 1. leads da recepção chegam com `equipe = "61 Imóveis"` e `atendimento =
>    "Atendimento/Recepção"` — entram no total da empresa mas **não têm equipe**, por isso a
>    soma por equipe fica menor que o total (88 de 475 em agosto);
> 2. parte da base legada gravou **nome** em `atendimento` em vez do id (a Renata tinha 80
>    leads assim). Os relatórios por corretor casam id **ou** nome por causa disso.
