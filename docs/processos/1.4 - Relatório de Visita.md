# 1.4 — Relatório de Visita (PDF)

> ⚠️ **Rascunho automático** inferido de `back-end/app/services/visita_service.py` e
> `relatorio_visita_service.py`. Validar quem preenche e obrigatoriedades.

## 1. Objetivo
Registrar a **visita a um imóvel** (cliente + parceiro + avaliação) e gerar um **relatório em PDF**,
arquivado no Google Drive. Alimenta os dashboards de visita do gerente. Front: `NovaVisita`,
`FormVisitaApp`, `GestaoClientesVisitas`.

## 2. Regras de Negócio
- **Modelo de dados (banco):** `visitas` liga `clientes_visita` e `parceiros_visita` via N:N
  (`visita_cliente`, `visita_parceiro`) + `avaliacoes_visita` (ver [[MAPA_BANCO]]).
- **Avaliação** por critérios canônicos (Localização, Tamanho, …).
- **Dupla gravação (as-is):** grava no **banco** (domínio visitas) **e** espelha no **Google Sheets**
  de visitas (`1we1qAVRBqAWaXmOfnLnFJzCi8WPt-ZEhxKb0Ab9DiQU`).
- **PDF no Drive:** OAuth de **usuário real** (não service account) grava no "Meu Drive", pastas
  `61_Visitas/` → `Fato_Visitas_PDF`, `Relatorios_Visita_Gerados`, `Relatorios_Cliente_Gerados`.
- **OAuth:** `oauth.json` (client) + `token.json` (gerado 1x via `ensure_oauth_token`); em produção
  o `token.json` precisa ir junto. Scopes: `drive.file` + `spreadsheets`.

## 3. Fluxo
1. Corretor lança a visita no front → `POST /api/v1/visitas` (grava banco + Sheets).
2. Buscas de apoio (autocomplete): `/imoveis_busca`, `/clientes_busca`, `/leads_busca`,
   `/visitas_busca`, `/corretores/<id>/imoveis`.
3. **PDF:** `GET /visitas/pdf` (gera) e `/visitas/pdf/download`; `/upload_pdf` envia ao Drive.
   Relatório de cliente: `/clientes/pdf`(+`/download`).
4. Gerente acompanha via `/visitas/vistas` (controle de leitura) e dashboards ([[2.1 - Dashboards do Gerente]]).

## 4. Troubleshooting
| Sintoma | Causa provável (código) | Ação |
|---|---|---|
| PDF não sobe / erro Drive | Token OAuth expirado (`RefreshError`) | Rerodar `ensure_oauth_token` (ver README back) |
| Token some após deploy | `token.json` não foi levado à VM | Copiar `token.json` p/ produção |
| Imóvel não aparece na busca | `db_loaders`/Imoview sem o código | Conferir base de visitas / Imoview |
| Visita no Sheets ≠ banco | Dupla gravação divergiu | Validar migração p/ banco como fonte única (to-be) |
