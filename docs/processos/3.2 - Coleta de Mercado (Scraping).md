# 3.2 — Coleta de Mercado (Scraping)

## 1. Objetivo
Coletar dados de mercado do **DFImóveis** semanalmente para formar a base `imoveis`, insumo da
precificação ([[3.1 - Precificação por Mercado]]) e do relatório de mercado no Power BI.
- Scraper **interno em Python**, semanal, ~**40k+** imóveis/semana → banco.
- Portal: **só DFImóveis** (venda e aluguel).
- Mensal: script gera `estudo_metricas` a partir da base acumulada.

## 2. Regras de Negócio
- **Acúmulo:** a base **sempre acumula** (~7M linhas) — guarda **dados brutos**; só remove
  **outliers muito óbvios** na coleta, o resto é filtrado **na análise**. (Filosofia: manter bruto,
  refinar depois.)
- **Escopo:** venda **e** aluguel (campo `oferta`).
- **Saídas da análise:** clusters, médias, médias entre clusters e **segmentos com vários filtros**
  (múltiplas combinações → cobre muitas consultas do site).
- **`estudo_metricas` (mensal):** **full replace** — apaga o conteúdo atual e regera com os dados
  acumulados. Alimenta o serving da precificação (segmentos `QUARTOS_VAGA/CLUSTER_VAGA/
  METRAGEM_VAGA/GERAL_VAGA`, `vaga_cat`, `cluster_nome`, `metragem_fx`, `quartos`, `m2_medio`,
  `preco_mediana`…).

## 3. Fluxo
**Onde roda:** máquina **local** (execução manual, sem automação).

**Semanal:**
1. Raspa DFImóveis (Python).
2. Remove outliers óbvios.
3. Envia (append) para o banco → `imoveis` (conexão local → RDS).

**Mensal (início do mês):**
4. Script de análise (script + banco) → grava `estudo_metricas` (full replace).
5. Com os dados analisados, gera o **relatório no Power BI**.

> ⚠️ **A verificar:** que o script mensal gere **exatamente** as colunas que o serving
> (`analise_service.consultar_estudo_metricas`) espera. O script está **fora do repo** (máquina local).

## 4. Troubleshooting
| Sintoma | Causa | Situação / Ação |
|---|---|---|
| Scraping cai | Sem automação de execução | Rodar de novo manual (sem retry) |
| DFImóveis muda/bloqueia | Mudança no portal | Manutenção manual do scraper |
| Semana sem coleta | Coleta não rodou | Prejudica só a visualização (não quebra) |
| `estudo_metricas` errado | Regeneração full replace | Sem mês anterior p/ rollback |
| Conexão | — | Local → RDS direto |

**Riscos/lacunas:**
- ⚠️ **Ponto único:** scraper + geração mensal só na máquina local, manual. Sem automação.
  **Validar se estão versionados/backupeados** (hoje aparentemente não).
- ⚠️ **Sem histórico de `estudo_metricas`** (full replace) → sem rollback fácil.
- ⚠️ **Credenciais do RDS na máquina local.**
