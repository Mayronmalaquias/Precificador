# 2.1 — Dashboards do Gerente (BI)

> ⚠️ **Rascunho automático** inferido dos serviços de gerente. Validar acesso e fonte dos imóveis.

## 1. Objetivo
Consolidar, para o gerente/diretoria, a performance da equipe: imóveis, corretores, visitas,
clientes, ranking e evolução temporal. Front: `RelatorioGerente`, `VisitasEvolucao`,
`GestaoClientesVisitas`.

## 2. Regras de Negócio
- **Escopo por equipe:** o gerente vê a **própria equipe** (`id_gerente`/`team`); diretoria vê tudo.
- **Fonte:** lê do Postgres via `db_loaders` (formato compatível com as antigas abas do Sheets —
  ver [[2.6 - Sincronização com Planilhas]]).
- **Evolução de visitas:** dimensões `total · equipe · corretor · proposta · quartos · cliente ·
  imovel · tipo_captacao`; agrupamento `dia · semana · mes`.
- **PDFs** (corretor/gerente/equipe) reusam os helpers de Drive do `visita_service`
  (mesmo OAuth do [[1.4 - Relatório de Visita]]).
- **Gestão de clientes:** ações sobre cliente (`cliente_acao`) integradas ao dashboard.

## 3. Fluxo
Endpoints sob `/api/v1/gerente-dashboard`: `/dashboard`, `/imoveis`, `/corretores`, `/visitas`,
`/clientes`, `/ranking`, `/serie`, `/visitas/evolucao` (+`/opcoes`), `/visita/detalhe`,
`/gestao-clientes` (+`/acoes`, `/acoes/<id>`), `/equipes/dashboard`; PDFs: `/corretor/pdf`
(+`/download`), `/gerente/pdf` (+`/download`), `/equipes/pdf/download`.

## 4. Troubleshooting
| Sintoma | Causa provável | Ação |
|---|---|---|
| Gerente sem dados | `id_gerente`/`team` errado no cadastro | Ver [[1.3 - Cadastro de Usuários]] |
| PDF não gera | Token OAuth do Drive | Rerodar `ensure_oauth_token` |
| Números divergem do ranking | Fontes/regra diferentes | Cruzar com [[2.2 - Rankings]] |
| Corretor duplicado | Nome não normalizado | Ver de-para [[MAPA_BANCO]] |
