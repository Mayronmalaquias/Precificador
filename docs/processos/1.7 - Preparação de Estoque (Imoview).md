# 1.7 — Preparação de Estoque (Imoview → `Fato_Estoque`)

> 🆕 Passo de preparação que antecede a rotina de estoque do Apps Script. Repo **`Estudos`**:
> `Estoque/tratamento_estoque.py`, `tratamento_estoque_imoview (1).py`, `Estoque/testeDIsponiveis.py`.

## 1. Objetivo
Converter o **export de imóveis do Imoview** no formato exato que a função `processFile(data)` do
Apps Script espera, para carregar o snapshot de estoque na planilha.

## 2. Regras de Negócio

### `Estoque/tratamento_estoque.py` (principal)
- Entrada: `imoveis-YYYY-MM-DD.xlsx` (aceita `.csv` testando `;` e `,`; se o Excel falhar, tenta
  **`read_html`** — o export "xls" do Imoview costuma ser **HTML disfarçado**, pegando a maior tabela).
- Exige a coluna **`Codigo`** ou **`Código`** (senão levanta erro listando as colunas encontradas).
  `Captadores` ausente vira coluna vazia.
- **Captadores:** quebra por `|`, no máximo **3**.
- **Saída: exatamente 6 colunas, nesta ordem** —
  `Codigo | Captador1 | Captador2 | Captador3 | Gerente | DataEstoque`
  - `Gerente` sai **vazio de propósito** (o Apps Script preenche);
  - `DataEstoque` = **data de hoje**, gravada como **data nativa do Excel** (`YYYY-MM-DD`);
  - linhas sem código são descartadas.
- Arquivo gerado: `Fato_Estoque_IMPORTAR.xlsx`.

### `tratamento_estoque_imoview (1).py` (variante mais antiga, na raiz)
- Mesma leitura robusta (detecta HTML disfarçado por sniff dos primeiros bytes).
- **Monta `Endereco`** concatenando `Endereco + EnderecoNumero + Bloco + Complemento`.
- Aceita `Captadores` **ou** `Captador1/2/3` já separados (`Captadores_final`).
- Exporta um Excel "padrão final" mais largo — **não** o layout de 6 colunas.

### `Estoque/testeDIsponiveis.py` (conferência)
- Consulta `POST https://api.imoview.com.br/Imovel/RetornarImoveisDisponiveis` para uma **lista de
  códigos colada no próprio arquivo**, em lotes de 120, e diz quais estão disponíveis.
- Parâmetros: `FINALIDADE=2` (venda), `NUM_REGISTROS=20` (máximo da API), `SITUACAO=1` (vago/disponível).
- Robustez: `RETRIES=4` com backoff `1.6`, timeout 45s, 0,25s entre requisições.
- Saídas: `resultado_disponibilidade.csv`, `disponiveis.txt`, `indisponiveis.txt`.

### `correcaoTrueFalseclv.py` (raiz)
- Limpa `Dim_Imovel.csv`: remove o apóstrofo inicial e aplica `UPPER` em `Foco PP` / `Foco AC`.
  Gera `Dim_Imovel_corrigido.csv`. Sintoma tratado: a planilha às vezes devolve booleano como
  texto `'TRUE`. Ver [[2.11 - Registro de Captação e Saída]].

## 3. Fluxo
1. Exportar os imóveis no Imoview.
2. Ajustar `INPUT_FILE` em `Estoque/tratamento_estoque.py`.
3. `python Estoque/tratamento_estoque.py` → `Fato_Estoque_IMPORTAR.xlsx`.
4. Importar o XLSX pelo Apps Script (`processFile(data)`).
5. (Opcional) `testeDIsponiveis.py` para conferir a disponibilidade de uma lista de códigos.

## 4. Troubleshooting
| Sintoma | Causa provável (código) | Ação |
|---|---|---|
| `Não encontrei a coluna 'Codigo' ou 'Código'` | Export com outro layout | Conferir a lista de colunas impressa no erro |
| `Não foi possível ler o arquivo fornecido` | `.xls` HTML sem tabela reconhecível | Reexportar em `.xlsx` |
| Código saiu como `12320.0` | Float do pandas | Já tratado por `clean_str`; se persistir, ler com `dtype=str` |
| `DataEstoque` como texto na planilha | `valueInputOption` / formatação | O XLSX grava data nativa; conferir na importação |
| Apps Script recusa o arquivo | Layout ≠ 6 colunas | Usar `tratamento_estoque.py` (a variante da raiz gera outro layout) |
| API do Imoview retorna vazio | `FINALIDADE`/`SITUACAO` divergentes ou `codigoacesso` exigido | Descomentar o header `codigoacesso` |
| Import repetido no mesmo dia | `DataEstoque` = hoje, sem dedup | Conferir antes de reimportar |

**Riscos/lacunas:**
- 🔴 **Chave da API do Imoview hardcoded** em `testeDIsponiveis.py` (arquivo versionado).
  Ver [[2.9 - Gestão de Segredos]].
- ⚠️ **Lista de códigos colada dentro do script** — sem arquivo de entrada.
- ⚠️ **Duas variantes** de tratamento de estoque com saídas diferentes.
- ⚠️ `DATA_ESTOQUE` é sempre "hoje": não dá para reprocessar um estoque retroativo sem editar o código.
