# 3.10 — Scraper DFImóveis (execução)

> 🆕 Esta nota **materializa** o scraper que [[3.2 - Coleta de Mercado (Scraping)]] descrevia como
> "fora do repo / só na máquina local". Ele **está versionado**, no repositório **`Estudos`**
> (`dfimoveis_scraper/scraper.py` + `README.md`). O que continua fora de automação é a **execução**.

## 1. Objetivo
Raspar os anúncios de **venda e aluguel** do portal **DFImóveis** e gerar um **CSV diário**
(`YYYY-MM-DD.csv`) que alimenta a carga da base `imoveis` ([[3.11 - Carga da Base imoveis]]).

- Entrada: nenhuma (varre o portal).
- Saída: 1 CSV por execução, nomeado com a data da coleta.

## 2. Regras de Negócio
- **Estratégia de escopo (`--escopo bairros`, padrão):** percorre **cidade/bairro** nas cidades
  grandes e **cidade direta** nas menores. Motivo: a busca geral `/df/todos` **corta resultados**
  no limite de paginação do site. (`--escopo todos` mantém a estratégia antiga.)
- **Mapeamento fixo no código** (`BAIRROS_POR_CIDADE` / `CIDADES_SEM_BAIRRO`):
  - `brasilia` → 21 bairros (asa norte, asa sul, noroeste, sudoeste, lago norte, lago sul,
    jardim botanico, park sul, park way, octogonal, taquari, …);
  - `aguas claras` → ade, areal, arniqueira, norte, sul;
  - **28 cidades sem bairro** (ceilandia, taguatinga, guara, sobradinho, vicente pires, gama,
    samambaia, valparaiso de goias, luziania, …).
  - `CIDADE_ALIASES` corrige grafias (`aguas-lindas-de-goiais` → `aguas lindas de goias` etc.).
- **Parada por escopo:** avança a paginação até a **primeira página vazia** ou **404**.
- **Deduplicação:** por `link`, dentro da mesma execução (`seen_links`). Não há dedup entre execuções.
- **Detalhe do imóvel:** por padrão abre a **página de detalhe de cada anúncio** — é lá que ficam
  `codigo`, `latitude`, `longitude`, `creci`, `area_util` confiável. `--sem-detalhes` roda muito
  mais rápido, mas perde esses campos.
- **Delay padrão 1s** entre requisições; timeout 30s; User-Agent de navegador.
- **Checkpoint:** reescreve o CSV de saída **a cada linha adicionada** — se a execução cair no meio,
  o que já foi coletado está no disco.
- **Layout do CSV (18 colunas):**
  `id, link, codigo, creci, anunciante, tipo, tipo_imovel, area_util, bairro, cidade, preco,
  valor_m2, quartos, vagas, latitude, longitude, quadra, data`
  onde `tipo` = operação (`venda`/`aluguel`) e `tipo_imovel` = categoria (`casa`, `apartamento`…).
- **Normalização:** `fix_mojibake` (latin1→utf-8) para acentos quebrados; preço/área via
  `parse_decimal_text` (descarta centavos); bairro/cidade em UPPER.

## 3. Fluxo
**Onde roda:** máquina local, venv própria (`dfimoveis_scraper/.venv`), execução manual.

```powershell
cd "...\Estudos\dfimoveis_scraper"
.\.venv\Scripts\Activate.ps1
python scraper.py --oferta ambos --inicio 1
```

1. `build_scopes()` monta a lista de escopos (cidade ou cidade/bairro).
2. Para cada oferta × escopo, pagina `.../{oferta}/df/{cidade}[/{bairro}]/imoveis?pagina=N`.
3. `parse_listing()` lê os `article[itemtype="https://schema.org/RealEstateListing"]` do HTML.
4. Para cada card novo, baixa o detalhe e faz merge (`parse_detail` lê `window.imovelFiltro`,
   lat/long por regex, código pelo rótulo "Código").
5. Grava/atualiza o CSV (`utf-8-sig`, `QUOTE_ALL`).
6. O CSV entra na carga do banco → [[3.11 - Carga da Base imoveis]].

**Flags úteis:** `--cidades "brasilia"` · `--bairros "altiplano leste"` · `--limite 5` ·
`--fim 5` · `--arquivo-listagem <html local>` (teste offline sem rede).

## 4. Troubleshooting
| Sintoma | Causa provável (código) | Ação |
|---|---|---|
| Bairro/cidade nova não aparece | Não está em `BAIRROS_POR_CIDADE`/`CIDADES_SEM_BAIRRO` | Adicionar no mapa e reexecutar só aquele escopo |
| `Cidade sem mapeamento: X` (SystemExit) | `--cidades` com nome fora do mapa/alias | Corrigir o nome ou cadastrar alias |
| Coleta muito abaixo do normal | Escopo parou cedo (página vazia intermitente) | Rodar o escopo isolado com `--inicio` na página suspeita |
| Acentos quebrados (`Ã`) | Encoding do portal | Já tratado por `fix_mojibake`; se persistir, checar `response.encoding` |
| `codigo`/lat/long vazios | Rodou com `--sem-detalhes` | Rerodar com detalhes |
| Execução caiu no meio | Sem retry automático | O CSV de checkpoint tem o parcial; retomar com `--inicio` |
| Coleta lenta | 1 requisição de detalhe por imóvel + delay 1s | Reduzir `--delay` com parcimônia (risco de bloqueio) |

**Riscos/lacunas:**
- ⚠️ **Execução manual, sem agendador e sem alerta** — semana sem coleta passa despercebida.
- ⚠️ **Sem retry**: `RequestException` no detalhe só imprime e segue; erro na listagem estoura.
- ⚠️ **Acoplado ao HTML do DFImóveis** — mudança de layout quebra os seletores silenciosamente
  (retorna 0 cards = "página vazia" = para o escopo).
- ⚠️ **Só DFImóveis.** Nenhum outro portal.
