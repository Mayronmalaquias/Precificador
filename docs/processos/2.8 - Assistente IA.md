# 2.8 — Assistente IA (chat do site)

> "Sofia" era o nome antigo — sobrou só nos ids de CSS `sofiaGrad`/`sofiaGradSm` (cosmético).

## 1. Objetivo
Assistente virtual no site público que ajuda o cliente a **encontrar imóveis**, **avaliar preço**
e receber **dicas de anúncio** — tudo baseado em dados reais. Front: `ChatWidget`.

## 2. Regras de Negócio
- **Modelo:** `claude-sonnet-4-6`, `max_tokens=1024`, `SYSTEM_PROMPT` fixo (persona + regras de formatação).
- **3 ferramentas (tools):**
  - `buscar_imoveis` — busca na tabela `imoveis` (scraping); até **5** resultados, últimos **365 dias**,
    só com `link`. Filtros: oferta (Venda/Aluguel/Temporada), tipo, bairro, quartos, preço min/max.
  - `precificar_imovel` — chama `consultar_estudo_metricas` ([[3.1 - Precificação por Mercado]]).
  - `dicas_anuncio` — estatísticas sobre até **200** imóveis do segmento (preço/área/quartos/vagas).
- **Loop agêntico:** processa `tool_use` até `stop_reason == end_turn`.
- **Histórico:** em memória (`_sessions[session_id]`), **máx. 20 mensagens** (corta p/ controlar custo).
  ⚠️ **Não persiste** — reinício do servidor zera as conversas.
- **Chave:** `ANTHROPIC_API_KEY`.

## 3. Fluxo
1. `ChatWidget` envia `POST /api/v1/chat` com `{ session_id, message }`.
2. `chat()` adiciona ao histórico → chama Claude com as tools.
3. Enquanto Claude pedir ferramenta, executa (`buscar_imoveis`/`precificar_imovel`/`dicas_anuncio`)
   e devolve o resultado; repete até resposta final.
4. Retorna o texto final; trunca histórico em 20.

## 4. Troubleshooting
| Sintoma | Causa provável (código) | Ação |
|---|---|---|
| "Nenhum imóvel encontrado" | Filtro restrito / fora dos 365 dias / sem `link` | Ampliar filtros |
| Conversa "esqueceu" o contexto | Histórico em memória, cap 20, some no restart | Esperado hoje; avaliar persistência |
| Erro ao responder | `ANTHROPIC_API_KEY` ausente/limite | Conferir chave/quota Anthropic |
| Ids CSS `sofiaGrad` | Resquício do nome antigo (Sofia) | Cosmético; renomear p/ `renataGrad` quando conveniente |
